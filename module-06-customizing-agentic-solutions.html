03 可觀測性與監控
CloudWatch 生成式 AI 可觀測性 — AgentCore Agents 儀表板三種檢視

AAgent 檢視

帳戶內所有 Agent 的整體健康度、效能指標與執行狀態，用於容量規劃與比較。

SSession 檢視

監控使用者與 Agent 的完整互動：對話情境、session 時長、參與模式。

TTraces 檢視

追蹤使用者互動細節，用於理解使用行為並優化對話流程。

04 Agent 互通性
A2A 標準化 Agent 間協作、MCP 標準化 Agent 與工具的溝通

A2A Protocol Agent 對 Agent

  • 開放標準，讓 AI Agent 之間安全、可擴展地溝通
  • 以 Agent Cards 讓彼此探索能力
  • 適合分散式任務委派與 Agent 專責分工
  • 依 Agent 數量規模化擴展

MCP Agent 對工具

  • 開放標準，讓 LLM 存取工具與資料
  • 透過 MCP server / host 集中控管
  • 適合工具協調與多來源上下文整合
  • 依工具端點數量規模化擴展
