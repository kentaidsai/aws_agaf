01 開源框架比較
Open-source frameworks — 優點與需留意之處

1CrewAI

角色分工清晰、短長期記憶穩健、社群活躍

留意：較為主觀、外部 Agent 支援有限

2LangGraph / LangChain

可處理複雜狀態流程、Agent 可自帶（node 化）

留意：版本間可能不穩定、依賴 LangChain 堆疊

3LlamaIndex

進階 RAG 與索引能力、可組合查詢引擎

留意：控制流常需外部協調器

4Strands Agents SDK

模型導向、極少樣板程式碼、內建可觀測性

留意：較新框架、社群規模較小

03 Amazon Bedrock AgentCore
正式上線 Agent 的專屬 Runtime 與身分管理服務
簡化工具探索與整合、提供短期與長期記憶、端到端追蹤除錯監控，並內建全託管的瀏覽器與程式碼執行能力 — 支援任何模型、任何框架。
1

Runtime

專為 Agentic workload 打造的執行環境

2

Gateway

統一存取入口，加速 Agent 開發整合

3

Memory

短期與長期記憶能力

4

Identity

對內、對外的身分驗證管理

5

Browser

全託管的網頁瀏覽與流程自動化

6

Code Interpreter

7

Observability
