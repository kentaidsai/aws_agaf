Intro 什麼讓一個系統是「Agentic」？
Agentic 系統 = 大型語言模型（LLM）+ 三個獨立的架構元件。三者持續循環運作，讓系統能自行探索、行動並修正策略。
感知 Perception 推理 Reasoning 行動 Action
常見工具類型（Common tool types）
RAG 與記憶體 檔案操作 Shell 與系統 程式碼執行 網路與連線 通用工具
Model Context Protocol（MCP）— 標準化的 server–client 架構，提供資源／工具抽象化、平台無關、可延伸的整合方式，是 Agent 串接外部工具的共通協定。

02 四種 AI Agent 類型
Types of AI agents — 依複雜度與自主程度遞增排列
工作流
Workflow agents 遵循預先定義路徑，執行快速、結果可預期
限制：只能照既定步驟走，難以隨機應變
自主
Autonomous agents 結合檢索、記憶體與工具自行協調決策
限制：執行速度較慢
混合
Hybrid agents 以路由器判斷任務，兼顧速度與彈性
限制：建置與維護成本較高
多代理
Multi-agent systems 多個專責 Agent 協作組成 AI 團隊
限制：透明度、可預測性與可解釋性較弱

Agentic AI applications
