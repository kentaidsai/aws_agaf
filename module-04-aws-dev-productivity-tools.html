01 Amazon Quick Suite
整合資料分析、研究與任務自動化的單一介面
面向商業智慧與分析的Agentic 助理：具備存取政策與權限控管，能提供可執行的洞察與自動化工作流。
1

Quick Index

安全串接企業各處資料源，讓 Agent 回應更豐富、有根據。

2

Spaces

上傳團隊專屬資料，建立自訂知識庫，讓 Agent 聚焦相關資料。

3

統一聊天助理與自訂 Agent

跨企業資料與網路提問、上傳檔案、存取儀表板，並可切換專責 Agent。

4

Quick Research

設定研究目標與範圍，自動規劃來源並產出深度研究報告。

5

Quick Flows

用自然語言建立、共享可重複使用的自動化工作流。

6

Quick Automate

端到端協調複雜商業流程，支援多系統整合與分支決策邏輯。

02 Amazon Q Developer
貫穿整個軟體開發生命週期（SDLC）的 Agentic 助理
專為開發者與 IT 人員打造：原生整合 AWS 服務與 IDE、注重安全與隱私、可用自有資料客製化，並提供因應特定情境設計的專屬助理。
探索與規劃 規劃新功能、理解 AWS API、詢問內部程式碼庫
→
開發 IDE / CLI 內建協作、對話式編碼
→
測試與安全 產生單元測試、掃描並修復安全漏洞
→
審查與部署 自動化程式碼審查、評估部署風險、產生文件
典型使用情境
查詢 AWS 文件 加速開發 強化安全 故障排除 API 整合 效能優化
Q Developer CLI — 在終端機中執行 Agentic 指令：用 fs_read／fs_write 工具讀寫檔案、進行 AWS 疑難排解，並可設定逐步確認或全權信任的執行層級。
動手實作 Lab — Accelerating Software Development Using Amazon Q Developer：安裝擴充套件、以對話 / 註解 / 程式碼提示互動、產生程式碼片段並取得說明。
03 Kiro：Spec-Driven 開發 IDE
從「編碼助理」進化為「開發協調者」
建構於 Code-OSS 之上的 AI IDE，以 requirements.md → design.md → tasks.md 連結產品需求與技術實作，提供的是完整專案協調，而不只是程式碼生成。
Agent Steering Autopilot 全自動 Supervised 監督式 MCP 多模態情境處理 Agent Hooks

Amazon Q Developer Chat 導向

  • 結構化開發流程（prompt → production）
  • 完整程式碼庫推理與執行
  • Chat 與程式碼補全為主
  • 提出改善建議

Kiro Spec 導向

  • Spec 驅動、任務導向，透過 hooks 自動化
  • Agent hooks 可自主執行關鍵任務
  • 逐檔案協助：撰寫、補全、測試、除錯
  • 產出雛型與程式碼片段
